## 再取得

Python 3.10以降とPopplerの `pdftotext` が必要です。Pythonの追加依存はありません。依頼者のPDFを手元に置いて、リポジトリのルートで実行します。

```sh
python scripts/import-materials.py --pdf /path/to/English_Vocabulary_Target_1900.pdf
```

取得済みのHTMLで再現する場合は `--idioms-html /path/to/source.html` を付けます。両方の資料が期待する全番号を持つことを検証した後にJSONを更新します。欠落・重複・順序違い・空欄・文字化け・想定外のPDF行はエラーにし、未取得の項目を生成しません。上書き前の確認には `--output /path/to/review-data` を利用できます。

## データ契約と問題作成時の注意

各ファイルは、`id`・`number`・`english`・`japanese` の4項目を持つJSON配列です。IDは単語が `v1900-0001` 〜 `v1900-1900`、熟語が `i1000-0001` 〜 `i1000-1000`。元の番号順で保存しています。

1900単語は英語が1900種類、日本語全文が1896種類。1000熟語は英語が1000種類、日本語全文が967種類です。同じ意味の英語が複数あるため、四択の選択肢は表示文字列を重複させず、同じ意味を持つ別の表現が不正解として紛れないよう配慮します。元の一覧を再取り込みするときもこの点を確認してください。

添付ファイルや閲覧可能なページが存在することと、第三者の教材を一般公開で再配布する権利があることは別です。この記録は資料の出典・取得方法の記録であり、出版社やサイトによる利用許諾の記録ではありません。
