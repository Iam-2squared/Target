# 2player: 文字スタンプとライブ観戦 (2026-11-12)

## 文字スタンプ
- 送信できるのは「おつw」「うっまw」「お願いします」「あざした〜w」「もう一戦しよ」の5種類だけ。自由入力は認めない。
- 対戦者のみが送信でき、コート中央に約2.2秒間表示。観戦者にも同じ文字を表示。
- 画像ファイルのダウンロードは不要。送信するデータはスタンプ番号（1～5）、本人のKGS認証はサーバーで検証。
- 1人につき5秒間隔・1試合30回まで。記録は10分で整理対象になり、5分ごとの非公開Cronで消す。

## 観戦
- ログインしたKGSユーザーは進行中の試合一覧から選んで観戦できる。試合のボールと選手の位置、スコアと直近の移動が見える。
- 観戦者はシュート、賭け額の変更、キャンセル、轟の精算を一切できない。自分が対戦中の人は他試合を観戦できない。
- 公開対象は試合ID、プレイヤー表示名、ターン、スコア、フィールド座標、時刻と最新移動のみ。ルームコード、KGS本人ID、預かり金、残高、認証トークンや非公開入力は公開しない。
- 観戦者の名前は双方の対戦画面に「〇〇が観戦中」と表示。明示的退出で消し、通信切断時は35秒で表示対象から外す。
- 画像、対戦動画、長期の観戦履歴は保存しない。観戦プレゼンスは35秒で整理対象になり、Cronで掃除する。
- 認証済み同一オリジンAPI経由、Target秘密鍵でサーバー間通信する。匿名公開ルートは作らない。

## 影響しない既存機能
60秒ターン、3回時間切れ負け、賭け金の相互承認と精算、轟、ランキング、既存試合履歴、KGS本体、英単語テストは変更しない。

## 検証
- Targetの独立したPostgreSQL統合テストで本人・対戦者・観戦者、認証拒否、5つの文字、連投制限、退出、寿命、残高不変を検査する。
- KGS認証が必要な2player APIとレスポンスの秘匿性、画面のDOM構造をNodeのHTTPテストで確認する。
- 本番移行はTargetスキーマのロールバック試験後、Targetデータベース適用と事後検査を先に行い、最後に2player公開URLを切り替える。
