# 領土戦

> この機能は終了しました。マップ画面と入口は削除され、旧マップ・領土戦の読取り／操作APIは認証後に`410 MAP_REMOVED`を返します。新規処理・通信量予約・課金は行いません。過去の購入履歴と轟残高を保持し、暗記・ガチャは従来の共通ウォレットを使用します。以下は実装時の記録です。

外部サイトのマップを、40人で参加できる50×50の個人領土戦へ変更します。暗記・ガチャと同じ轟残高を使い、総所得と暗記ランキングには支出を反映しません。旧マップの購入履歴・所有者・残高は維持し、旧マップへの新しい見積り・購入は410 `MAP_REPLACED`で拒否します。

## ルール

- 40個の本拠地座標を最初から予約します。参加は無料で、本拠地に10兵を置きます。再参加で兵は増えません。本拠地は攻撃・占領から常に保護されます。
- 上下左右につながる空き通常マスを1,000轟で占領し、1兵を配置します。
- 自分のマスへの増援は1兵1,000轟、1マス最大1,000兵です。自分の隣接マスへの移動は無料で、出発マスに1兵以上残します。
- 攻撃は1回1,000轟です。自分の隣接マスから兵を送り、攻撃兵数と守備兵数の差で決着します。攻撃側が多いと残存兵で占領、少ないと守備側の残存兵が維持し、同数は中立・0兵になります。本拠地は攻撃できません。
- 城は5個、最初の守備兵は8兵です。通常領土は1分1点、城は1分10点で、保有時間を得点にします。城も領土数に含みます。
- 毎週月曜0時（日本時間）に新シーズンが始まります。得点、領土数、参加枠の順で順位を決めます。過去のシーズンと操作履歴は保存します。

## 台帳・同時操作

`public.target_territory_rpc(secret, action, input)`は、既存のサーバー資格情報を確認してから入力・料金・盤面を扱います。KGSサーバーがセッションから本人のID・名前を確定し、ブラウザーは本人・兵力残高・得点を指定できません。データと内部関数はprivateスキーマに置き、RLSと権限でクライアントの直接利用を拒否します。

操作は採点・ガチャ・旧マップと同じ991101のトランザクションロックを最初に取得します。その後にサーバー時刻をミリ秒に揃えて確定し、シーズン・残高・参加枠・所有者・上下左右の接続・兵数・対象マスのバージョン・確認金額・保存容量を検査します。出兵元と対象だけのバージョンを検査するため、無関係なマスの更新は操作を妨げません。

兵数・所有権・得点・支出・戦闘イベント・不変の操作履歴を同じトランザクションで保存します。操作UUIDの再送は、現在のシーズン・盤面・回数制限より先に既存履歴を確認します。過去の結果と最新残高を返し、後の兵力や所有権を再適用しません。同じUUIDの別内容は409です。ハッシュは名前を除くため、表示名が変わっても同じ操作を再確認できます。

`profiles.spent_points`は全支出、`wallet_snapshot.mapSpent`は旧マップと全シーズンの領土戦の支出合計です。既存のガチャ履歴・価格・確率と支出の整合性を維持します。元所有者への返金と仮の通貨付与はありません。

## 得点とシーズン

`territory_players.score_millis`は「保有領土の点倍率×ミリ秒」の整数です。所有権変更前に攻撃者と守備者の保有時間を精算し、通常領土1・城10の倍率で加算します。精算時刻はミリ秒境界に統一されるため、操作を繰り返しても端数時間を失いません。表示得点は`floor(score_millis / 60000)`、シーズン終了時刻で上限を設けます。

シーズン作成は共有ロックの中で行い、40個の予約本拠地・5個の城を含む2,500マスを生成します。状態の読取りはプレイヤーや暗記プロフィールを作成せず、明示的な参加操作だけが参加枠を取得します。41人目の新規参加は409 `PLAYER_LIMIT`です。

## 配信量

最初または別シーズンには、位置が配列順で決まる2,500個の`[ownerSlot,troops,version]`を返します。同じシーズンの過去リビジョンには`[index,ownerSlot,troops,version]`の変更マスだけを返します。現行リビジョンなら変更配列は空です。

`summaryMinute`・リビジョン・シーズンが一致する間、順位・イベント・被攻撃通知の配列もnullにして既存リストを保持します。残高・サーバー時刻は毎回更新します。新しい分では順位と履歴を更新します。レスポンスは256KiB、操作結果は4KiB以内に収めます。クライアントは表示中だけ10秒ごとに読み取り、操作結果のリビジョンで盤面を最新扱いせず、変更マスの適用後に更新します。

既存の100MiB論理容量へシーズン・プロフィール・参加者・不変操作履歴を加算します。状態・見積りは毎分120回、操作は毎分60回に制限します。確定済み操作の再確認は回数制限で遮断しません。SQLのタイムアウトは領土戦RPCだけ25秒です。
