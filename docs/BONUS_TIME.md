# 10万轟のボーナスタイム

2026-11-08現在、通常の正解報酬は100,000轟が2%、10,000轟が7%、1,000轟が20%、100轟が71%です。100,000轟が確定すると、提供された約16秒のMP3を再生し、周囲・背景を金色にします。期間内の正解は一律500轟、不正解は0轟で、期間中は通常抽選をしません。

## 時間と所得

認証済みテストではDBの時計で15,900msの終了時刻を保存します。本人単位で別の問題・テスト・端末へ引き継ぎ、再送・再読込・音なし・背景化で延長しません。古い回答は以前の報酬と終了時刻を返し、新しい10万轟を発生させません。正解・所得・ボーナス状態は採点の同じトランザクションで確定し、容量エラーでは未確定の時間を残しません。ゲストは同じ演出と確率を端末内の練習だけで使い、共有残高を増やしません。

`20261106083226_target_hundred_thousand_bonus.sql`は既存の採点関数のMD5を照合してから変更します。過去の回答・総所得・支出・購入履歴を残し、新しい10万轟・500轟に合わせてDB制約だけを広げます。新しい公開RPC・秘密・課金サービスは追加しません。Targetの残高をKGSで使う処理も維持します。

## 音と画面

提供されたMP3を加工せずに、正解・不正解音とは別のネイティブプレーヤーで再生します。次問への1秒後の自動進行・途中タップ・結果画面でも曲を切りません。曲の間は通常の短い正解・不正解音を重ねず、画面の読みやすさを保ちながら金色の枠・背景・残り時間を表示します。動きを減らす設定では装飾のアニメーションを止めます。

音あり／音なしの設定を維持します。自動再生が拒否される場合は「音を再生」や次の解答操作で残り位置から再開できます。消音・ログアウト・背景化で停止し、隠れた画面から遅れて再生を始めません。音声セッションの参照を管理し、短い音の停止が継続中の曲を停止しないようにしました。

15.9秒の報酬判定が終わったとき、再生中のごく短い末尾だけが残っていれば最大350msまで自然終了を待ちます。この余韻では500轟の判定・金色表示・期間を延長しません。音声を新しく再生する処理ではなく、消音・背景化・ログアウト等では余韻も即停止します。

HTTPの新しい時刻・処理時間ヘッダーを使い、サーバーの待機時間を往復通信の推定から除きます。同じボーナスの再取得では、単調時計に変換した終了時刻を後ろへ動かしません。ブラウザの時計や音源の再生状態を、記録する金額の根拠にはしません。

音源の原本・サイズ・ハッシュは[SOUND_ASSETS.md](SOUND_ASSETS.md)、DBの境界は[rpc.md](rpc.md)を参照してください。通常の1秒進行と、提供曲の長さに合わせたボーナスの時間は別に管理します。
