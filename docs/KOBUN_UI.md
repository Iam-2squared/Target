# 教材の選択と古文単語

ホームの教材欄はひとつのネイティブ選択欄です。Target 1900・英熟語Target 1000・古文単語をタップで選びます。古文単語は400項目、100項目ごとの4Sectionです。教材ごとにSectionの選択を分けて保持し、通常テスト・暗記にはその範囲を使い、解き直しと現在のミス件数は選んだ教材の全範囲を使います。

古文単語のテストでは、回答方向を「古語」「現代語訳」と表示します。暗記では古語と現代語訳を縦書きにし、右から左へ番号順に並べます。各項目の右側を青い古語欄、左側を淡い色の訳欄とし、番号は青い欄の上部に表示します。画面の高さで折り返した実際の列幅を計測し、スクロールせず収まる項目数でページを分けます。計測時の高さをピクセルで指定し、計測した列幅を表示にも使うことで、WebKitでの余白や項目の重なりを防ぎます。訳を隠してもページ分けは変わりません。英単語・英熟語は従来の横書きを使います。

内部の教材行とAPIの方向名は既存のenglish／japaneseを使用し、学習・採点・定着率・解き直し・報酬の既存経路へ渡します。公開画面には英語向けの説明を表示しません。

教材変更では保留中の定着率・ミス件数の応答を無効にします。教材データは公開の静的JSONとして教材ごとに読み込み、同一ページ内では取得を共有します。出典ダイアログから提供画像に対応する古文単語400の掲載ページを開けます。
