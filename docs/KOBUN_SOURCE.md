# 古文単語400の出典と転記

教材は、ユーザーが提供した古文単語プリントと同じ[ロジカル記憶「重要古文単語一覧400 暗記プリント」](https://logicalmemory.jp/707/)の原画像を使用しています。公開ページからリンクされる50語ずつ・全8枚の原寸JPEGを2026-11-07に確認しました。提供画像にない201〜250番も、同じ一覧の5枚目から確認しています。現在のページ本文にある紹介例ではなく、番号付きの原プリントを転記基準にしています。

`data/kobun400.json` は番号1〜400の全400項目を元の順番で収録し、IDは `k400-0001`〜`k400-0400` です。既存の教材と同じ内部形式を使い、`english` に古語、`japanese` に現代語訳を格納します。古語の重複はありません。アプリの配信には約50KBのJSONだけを使い、原画像の一括ダウンロードを必要としません。

原画像を目視して転記し、番号・古語・訳を確認しています。自動OCRの初回結果は罫線や薄い文字を正しく認識できなかったため、最終の転記として採用していません。201〜400は別担当者の転記に対して原画像を再確認しています。

波ダッシュは表示が同じなのに選択肢が別文字列になることを避けるため `〜`（U+301C）に統一し、日本語訳の括弧は全角にしています。元の番号・古語・意味・句点のない表記をそのほかは保持しています。各原画像のURL、バイト数、SHA256と完成JSONのSHA256は `KOBUN_SOURCE.json` に記録しています。原画像は教材配信物やリポジトリへ追加していません。

原プリントにある以下の表記は、推測で書き換えずそのまま残しています。

- 7番「かたち」の訳に「子。」を含みます。
- 246番「こうず」の訳は「困る。値やむ。苦しむ。」です。
- 259番「すだく」の訳は「群がる。集さわぐ。」です。
- 255・272・323・399番など、末尾に句点のない項目があります。

構造確認では、全400連番、400個の一意ID、各行の空でない古語と訳、4つの100語範囲を確認しています。
