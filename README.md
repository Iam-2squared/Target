# Target

KGS 11thの雰囲気に合わせた英単語・英熟語の暗記と4択テストです。

- Target 1900と英熟語Target 1000を選択し、英語と訳を左右に大きく表示して暗記できます。番号は青い英語欄にまとめ、横幅を広く使い、画面内に収まる件数を表示します。
- 英語／訳のどちらを答えるかを選び、1問ずつ4択でテストします。
- 100項目ずつのSection（単語1〜19・熟語1〜10）から、1つまたは連続範囲を選んで暗記・テストできます。問題数は10・50・100問です。
- Section横の「定着率」で、各Sectionの定着した単語の割合を確認できます。同じ単語に2回連続で正解すると定着、間違えると未定着に戻ります。「解き直し」は、選択した範囲で間違えてからまだ2回連続正解していない単語を出題します。記録はログインした本人に結び付き、別端末でも共有します。
- 選択肢を1回タップすると正誤を表示します。選択肢は大きな太字で、共有の得点と進捗はサーバー確認後に確定します。
- 通常の正解は100,000轟（1%）・10,000轟（2%）・1,000轟（15%）・100轟（82%）を抽選します。「轟」はアプリ内の得点で、実際の金銭ではありません。短い正解・不正解音と、今回の正解数・合計点を表示します。
- 100,000轟に当選すると添付音源と金色の画面で約16秒のボーナスタイムに入り、その間の正解は一律500轟・不正解は0轟です。再送・消音・画面切替で判定時間を延長しません。
- 獲得演出は金額が高いほど華やかになります。すべての金額と不正解の結果を確定後1秒表示して自動で次問へ進み、表示中のタップでも進めます。最後の問題の後は結果画面を開きます。
- 個人設定で保有金額と総所得を確認し、「音あり／音なし」を切り替え、この端末に保存できます。正解は提供されたDing Dong、不正解はBuzzerのShort版です。10,000轟以上の当選で画面の上から札束が降ります。
- KGSアカウントの番号とPINでログインすると、サーバーで確定した累計点数をユーザー名でランキングに表示します。ゲストは記録なしで練習できます。既存の正解記録を保持し、抽選得点は導入時点の0から加算します。
- KGS 11thの仮想購入で、100,000轟につき未獲得スタンプを1つ入手できます。過去の10,000轟の購入履歴は変更しません。保有金額は総所得から利用額を引いた値で、総所得・ランキングは減りません。4種類をそろえると購入は止まります。
- ホームにはランキング上位10人を表示し、「ランキング」を押すと全員分を見られます。ホームへ戻るたびに再取得します。
- PIN・認証トークン・サーバー資格情報を公開ファイルやブラウザ保存領域へ保存しません。

公開先： https://kgs-target.vercel.app/

`npm ci` → `npm run build`。ローカルサーバーは`npm start`、単体検証は`npm test`です。共有機能の環境変数は[.env.example](.env.example)を非公開で設定してください。
